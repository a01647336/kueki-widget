# Proyecto: Chrome Widget para Impulsar el Uso de Kueski

## Contexto

Kueski es una plataforma de financiamiento digital que permite a los usuarios pagar en comercios afiliados de forma flexible. Uno de los retos clave del negocio es **incrementar la adopción de Kueski** y **aumentar la frecuencia de uso por cliente** en comercios digitales.

Para este proyecto, deberán diseñar y construir un **widget (extensión) de Google Chrome** que acompañe al usuario mientras navega por internet y que lo ayude a **descubrir, entender y usar Kueski de forma más frecuente y conveniente**.

---

## Objetivo del Proyecto

Diseñar un widget que, al ser instalado por un usuario, **genere más clientes y/o más transacciones para Kueski**, influyendo de manera positiva en el comportamiento de compra del usuario mientras navega por sitios de e-commerce.

El foco del proyecto no es solo técnico, sino también **de producto y negocio**:

- ¿Por qué este widget haría que alguien use más Kueski?
- ¿Qué valor recibe el usuario en el momento exacto de la compra?
- ¿Cómo se reduce la fricción para pagar con Kueski?

---

## Idea General (Abierta)

El widget se activa cuando el usuario navega por un sitio web (por ejemplo, un e-commerce) y le muestra **información relevante, oportuna y accionable relacionada con el uso de Kueski**.

Cada equipo es libre de proponer **qué información mostrar, cuándo mostrarla y qué acciones permitir**, siempre que esté alineado con el objetivo de negocio.

---

## Ejemplos de Casos de Uso (Solo como referencia)

Los siguientes ejemplos **no son obligatorios**; sirven únicamente para inspirar ideas:

- Detectar si el sitio actual es un comercio que acepta pagos tipo "compra ahora, paga después".
- Mostrar promociones o beneficios simulados (descuentos, meses, cashback).
- Estimar el beneficio de usar este método de pago en una compra.
- Mostrar recordatorios contextuales durante el proceso de compra.
- Permitir guardar comercios favoritos o recibir alertas de promociones.
- Mostrar historial de beneficios o interacciones.
- Comparar de forma simple distintos métodos de pago.
- Permitir reportar información incorrecta o incompleta.

---

## Requisitos Generales

El proyecto debe incluir:

- Un **widget funcional de Chrome**.
- Un **backend simple** que provea información dinámica.
- **Persistencia de datos** mediante una base de datos.

Consideraciones adicionales:

- El widget **no debe depender de datos reales de Kueski**; toda la información puede ser simulada.
- Se espera una **propuesta clara de valor**, explicando cómo el widget ayuda a:
  - Captar nuevos usuarios, y/o
  - Incrementar el número de transacciones por usuario.

---

## Uso del Nombre y Publicación

- El widget desarrollado **no debe publicarse en la Chrome Web Store** bajo el nombre *Kueski*.
- En caso de que algún equipo decida publicarlo de forma independiente, deberá **usar un nombre distinto** y evitar cualquier uso de marca, logotipo o identidad visual de Kueski.
- El proyecto es exclusivamente con fines académicos.
