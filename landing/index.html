Funciones del widget

Seis modulos disenados para integrar Kueski en la navegacion diaria.

SR

Smart Reminder

Detecta el sitio actual y muestra el CTA de Kueski Pay en contexto. Incluye un banner de aviso cuando el proximo pago vence en 7 dias o menos.

SP

Simulacion de pagos

Calcula planes de quincenas personalizados por nivel y credito del usuario. Evalua la elegibilidad (mora, limite, credito) y pide confirmacion antes de registrar.

SC

Score Coach

Sistema de puntos y niveles (Bronce a Platino). Logros reales basados en el historial del usuario en la base de datos, con barra de progreso animada.

DF

Deals Finder

Muestra promociones de todas las tiendas compatibles. Cada tarjeta abre el sitio en una nueva pestana para ver la oferta en contexto real con el widget activo.

UP

Perfil de usuario

Muestra nombre, nivel, credito disponible, proximo pago, tasa de cashback e historial de compras expandible con el estado de cada transaccion.

CB

Cashback real

Cada compra acumula cashback calculado y persistido en la base de datos segun el nivel del usuario: de 0.5% en Bronce hasta 5% en Platino.

Stack tecnologico

Tecnologias seleccionadas para construir una extension de Chrome real con backend en la nube.

Extension de Chrome

  • Plasmo 0.90 — framework MV3 para extensiones
  • React 18 — UI con componentes funcionales
  • TypeScript — tipado estricto en todo el proyecto
  • Tailwind CSS v3 — estilos en Shadow DOM
  • Framer Motion — animaciones y transiciones
  • Lucide React — iconografia

Backend

  • Node.js — entorno de ejecucion
  • Express 4 — framework HTTP
  • pg — driver PostgreSQL nativo (sin ORM)
  • bcryptjs — hash de contraseñas
  • JWT HS256 — autenticacion con crypto nativo
  • CORS — acceso desde el content script

Infraestructura y pruebas

  • Aiven PostgreSQL — base de datos en la nube
  • Render — deploy del backend (Web Service)
  • Vitest 4 — framework de pruebas
  • Testing Library — pruebas de componentes
  • Supertest — pruebas de integracion HTTP
  • pg-mem — PostgreSQL en memoria para tests

Como funciona

Tres capas integradas: extension de Chrome, backend en la nube y base de datos PostgreSQL.

Extension de Chrome
  1. 1. Plasmo inyecta el content script en sitios compatibles (.com.mx)
  2. 2. PriceDetector lee el total del carrito del DOM con MutationObserver
  3. 3. El widget se monta en Shadow DOM (estilos aislados del sitio)
  4. 4. Los datos de sesion se cargan de chrome.storage.local
Backend en Render
  1. 5. El widget llama a la API con Authorization: Bearer JWT
  2. 6. El backend valida el token y ejecuta la logica de negocio
  3. 7. Los planes de pago se calculan con el nivel y credito del usuario
  4. 8. Si el backend no responde, el widget usa localStorage como fallback
PostgreSQL en Aiven
  1. 9. Tabla users: perfil, score, logros, credito
  2. 10. Tabla purchases: historial por usuario con FK
  3. 11. Tabla deals: catalogo de promociones
  4. 12. Cada usuario ve y modifica unicamente sus propios datos

Instalacion

Proyecto academico — se carga como extension descomprimida en modo desarrollador.

  1. 1

    Clonar el repositorio e instalar dependencias

    git clone https://github.com/a01647336/kueki-widget.git
    cd kueki-widget
    npm install
  2. 2

    Generar el build de produccion

    PLASMO_PUBLIC_API_URL=https://kueski-widget-api.onrender.com/api npm run build

    Genera la extension en build/chrome-mv3-prod/

  3. 3

    Cargar en Chrome

    Ir a chrome://extensions, activar el Modo desarrollador, clic en "Cargar descomprimida" y seleccionar build/chrome-mv3-prod/.

  4. 4

    Navegar a una tienda compatible

    Amazon, Mercado Libre, Liverpool, Coppel o Elektra (.com.mx). El widget aparece abajo a la derecha. El backend ya esta desplegado en Render — no se necesita correr nada localmente.
